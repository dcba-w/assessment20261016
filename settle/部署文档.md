# 从零部署

按下面顺序在一台新机器上启动。数据库密码和模型 Key 只放本机配置或环境变量，不写入仓库。

## 环境

- JDK 17、Maven 3.6+
- MySQL 8、Redis 6+
- Node.js >= 20.19、pnpm >= 8.6

## 1. 初始化数据库

```powershell
cd backend\sql\mysql
.\init-all.ps1 -Database simple-project
```

该脚本会建库并导入 `init.sql`（结构、Quartz、菜单和种子数据）。

## 2. 启动后端

1. 使用仓库里的 `backend/simple-server/src/main/resources/application-dev.yaml`。
2. 库名和密码默认是 `simple-project`、`root` / `root`，与初始化脚本一致。本机不同时用环境变量覆盖：`MYSQL_HOST`、`MYSQL_PORT`、`MYSQL_DATABASE`、`MYSQL_USERNAME`、`MYSQL_PASSWORD`。
3. 如需自然语言查数，设置 `NL2SQL_API_KEY` 或 `OPENAI_API_KEY`。未设置时问数降级，业务页面仍可登录。不要使用占位密钥。

```powershell
cd backend
mvn -pl simple-server -am clean package -DskipTests
java -jar simple-server\target\simple-server.jar --spring.profiles.active=dev
```

后端端口 48080。

## 3. 启动管理端

```powershell
cd frontend
pnpm install
pnpm dev
```

浏览器访问 http://localhost:80 。默认账号 `admin` / `admin123`，租户 Simple。

## 4. 核对

1. 能登录并打开系统管理、基础设施。
2. 浏览器网络面板里，这些页面的请求走 `/admin-api/**`。
3. 问数时，NL2SQL 只读取白名单里的表。令牌、密码、登录日志、操作日志不在白名单内。
